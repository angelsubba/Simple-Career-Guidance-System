# Simple Career Guidance System

## Project Overview
This is a beginner-friendly Python project that provides general career suggestions based on students' interests.

## Problem Statement
Students may find it difficult to explore career options that match their interests. This project helps them discover possible career paths.

## Objectives
- Explore students' career interests.
- Suggest possible career paths.
- Display relevant skills to learn.
- Practise Python programming.

## Technologies Used
- Python
- Visual Studio Code

## Features
- Accepts the student's name.
- Asks about the favourite subject.
- Asks about the area of interest.
- Suggests a possible career.
- Displays relevant skills.

## How to Run
Open the VS Code terminal and enter:

py career_guidance.py
